# Frozen filter-bank protocol

Use native SEAL 4.7.2, BFV, N=8192, coefficient-modulus bit lengths 60/60/60, t=65537, tc128. Two deterministic 64×64 images occupy separate batching rows. Bank sizes are 1, 2, 3, 4, 8. Each bank uses the first f kernels from eight distinct asymmetric, signed filters. Precompute scalar plaintexts and tree metadata. Each arm performs nine plaintext multiplications and eight additions per filter. All arms retain completed ciphertexts until the timer stops.

G4 shares the two horizontal shifts via the vector API and rotates two weighted row sums per filter. G3 shares the -65,+1,+1 seed chain and uses two +64 shifts per filter in Horner order. C3/C4/C6/C8 cache eight ciphertext views using sibling hoisting and parent strings 345141434/345444345/400044040/444444444. G4 uses four axial keys, G3 uses -65,+1,+64. Count direct rotation edges separately from hoisted API calls. Use common code for reductions, use references for input, move vector outputs, and avoid full ciphertext copies for seeding reductions.

Run ten fresh processes, each with a warmup sweep then six measured blocks. At each f and block use all arms on the same fresh encryption. For each bank size within each process, a six-treatment Williams square cycles [0,1,5,2,4,3] through all six additive shifts, balancing positions and immediate predecessors. Offset square row by process index. Rotate bank-size order by block/process. Time from encrypted input to vector of completed ciphertext outputs, including temporary cleanup, excluding output destruction, encryption, encoding, decryption, noise checks, and key generation. Verify every output in both 62×62 crops by 2D indexing and all 8192 cyclic slots separately. Use medians across process medians and paired block ratios aggregated similarly. All timings are specific to this host/build.
