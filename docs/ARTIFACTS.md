## Earlier encrypted-computation releases

The [original releases](https://github.com/rohit661x/research-lab/releases) remain attached to this lab with their original tags and downloads. Some tags include `private-preview`; these are historical names of publicly available artifacts. See the [study’s comparison and replay guide](https://github.com/rohit661x/rotation-key-latency/blob/main/docs/related-studies.md) to distinguish the BFV stencil, filter-bank and seven-convolution ResNet20 experiments.

## Citation and reuse

Use the citation metadata in the relevant repository and identify the exact revision. The lab’s project-authored code has no project-wide reuse license. Upstream software, data and notices retain their own terms. For permissions not otherwise granted, [contact the maintainer](https://github.com/rohit661x/research-lab/issues/new).
