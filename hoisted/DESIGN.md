# Prospective protocol

Four arms A through D use the row-major parent strings 345141434, 345444345, 400044040, 444444444 respectively. Root 4 is the original ciphertext. The offsets are {-65,-64,-63,-1,0,1,63,64,65}. Derive unique direct key steps from the edges. For each parent call the public vector overload once for a group with at least two children and call scalar rotate_rows once for a singleton. Each child is materialized exactly once. Every arm uses one shared input plus eight outputs, with vector results moved into their final storage (no ciphertext copies required by the scheduler). The root is referenced directly. Construct groups and step vectors outside timing. Each route then applies the identical weighted reduction with weights 1..9 in spatial row-major order. Use BFV N=8192, Q=60+60+60 coefficient bits, plain modulus 65537 and tc128.

Run 16 independent processes. In each process generate new keys, record uncompressed bytes, perform one warmup sweep, then encrypt the same two deterministic 64×64 images afresh in four paired measured blocks. All methods in a block use the same ciphertext. For four blocks cycle Williams orders ABDC, BCAD, CDBA, DACB, offset by process index. Include creation of ciphertext temporaries, rotations, and reduction in the elapsed interval. Exclude keygen, encryption, final decryption/verification, noise readout and final result destruction. Validate nine raw outputs at all 8192 slots and output at both 62×62 interiors after every route in warmup and measured blocks. Retain all observations. For each arm report the median across 16 process medians and their range. New process keygen timings are descriptive; key generation order is fixed. No host-to-host extrapolation.
